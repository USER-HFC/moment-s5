# 迭代 3 · 可访问性、查看器 LUT、关于页

模拟器 `moment_s5_wifi_api35`（`emulator-5564`，无窗口）上的 release 包。没有连接实体相机。相册里的一张是演示动态照片，画面上的「SYNTHETIC DEMO」是演示水印。

截图用 `adb emu screenrecord screenshot`。无障碍树用 `uiautomator dump`，先删掉旧的 `/sdcard/uidump.xml` 再抓。下面的标签文件只保留有文字或内容描述的节点，顺序与 dump 一致。

## 3.4 覆盖层前后对比

引导打开前，拍摄页 dump 里有这些控件：`构图网格`、`定时 关`、`打开相册`、`拍摄照片`、`构图参考 关`、`LUT 风格`。引导打开后（`labels-onboarding.txt`）这些都是 0 次，只剩「跳过引导」「下一步」和卡片正文。

查看器打开前，网格 dump 里有 `返回拍照页面`、`全部 1`、`演示动态照片，今天 22:01`。查看器打开后（`labels-viewer.txt`）这些都是 0 次，能读到的是查看器自己的「返回网格」「今天 22:01」「更换 LUT」。

更换 LUT 打开前，查看器 dump 里有 `返回网格`、`照片信息`、`播放动态照片`、`导出到系统相册`、`删除照片`。面板打开后（`labels-lut.txt`）这些都是 0 次，能读到的是「更换 LUT」、风格选项和底部提示。
