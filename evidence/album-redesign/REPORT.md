# 相册重新设计（v2）

模拟器 `moment_s5_task_e_api35`（API 35，无实体相机）。截图都是合成演示画面，没有个人信息。

数据与存储逻辑保持上一版：`original.jpg` 不被改写，LUT 从原片重新生成，动态照片用新静态图和原视频重新封装 `MOMENT_MP.jpg`。本轮只改了界面和交互，另外为 LUT 胶片条增加了一个只读的缩略图缓存。

## 本轮改了什么

### 查看器

- 去掉顶部、底部带描边的卡片，改成贴边的半透明黑色渐变栏，叠在照片上，不描边、不加阴影。
- 顶部：返回、居中标题、右侧 `3 / 11`。标题改为拍摄时间（`今天 16:22` / `昨天 16:22` / `10月25日 16:22`），副标题是一行 `来源 · 连接 · LUT`，重复项会去掉（例如演示照片只显示一次「演示」）。文件名移到信息面板。
- 单击照片切换沉浸模式：上下栏淡入淡出，同时隐藏/显示状态栏。硬件返回键在沉浸状态先恢复上下栏。
- 双击放大到 2.5 倍，再双击复原；双指缩放和放大后拖动仍然保留。
- 动态照片在照片左上角显示 LIVE 标记；点 LIVE 或长按照片播放，底部「播放」按钮保留。
- 「保存」改为「导出」，无障碍文案同步为「导出到系统相册」/「导出原片到系统相册」；导出提示改为「已导出到 DCIM/MomentS5」。
- 删除保留红色图标，文字和其它操作一样弱化，不再更醒目。
- 横屏下上下栏更薄（顶部 58dp、底部 60dp），操作居中，照片按 contain 占满可用高度。

### 信息面板

- 改成从底部升起的半高面板，不再用 Modal，所以上方照片仍可见；拖动顶部把手可以上滑展开、下滑关闭，硬件返回键可关闭。
- 顶部显示「机型 · 镜头」一行；ISO、快门、光圈、焦距四项横排成小方块。
- 分组为「文件」（机身文件、尺寸、大小）、「处理」（来源、连接、LUT）、「存储」（App 内目录、系统相册、导出位置）。
- App 内目录显示缩短路径（例如 `…/moments/…50cdd12a`），「复制路径」复制完整目录；复制后按钮短暂显示「已复制」。导出后显示 `已导出` 和 `DCIM/MomentS5/...`。
- 没有 EXIF 时不显示空参数行，改为一行「这张照片没有拍摄参数（EXIF）」；指标标签弱化、值保持正常色，行距压缩。

### 更换 LUT

- 改成横向胶片条：每个 LUT 显示用当前照片生成的小缩略图、名称、当前/已保存标记。缩略图在后台串行生成并写入应用 cache，界面不阻塞；再次打开会直接复用缓存。
- 照片保留在面板上方并尽量放大，选中 LUT 后实时预览；预览先用已生成的缩略图占位，再换成大图。
- 按钮为「取消」和「保存」。取消只清预览，不写盘。
- 按住照片临时显示 `original.jpg`，右上角出现「原片」标记，松开恢复预览。
- 动态照片的提示会说明实况会用新静态图重新封装、视频片段不动。

### 网格

- 按日期分组，显示「今天 / 昨天 / 日期」小标题。
- 保留 LIVE；「演示」改成小号弱化标记；机身快门同步的照片用小相机图标；套用 LUT 的照片加一个很小的 accent 圆点。
- 空相册显示「还没有照片」、一句说明和「去拍摄」按钮。
