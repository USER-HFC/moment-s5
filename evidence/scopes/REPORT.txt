Data protocol
API: MomentLumix.setScopesEnabled(enabled: boolean, rotateClockwise: boolean,
                                 sourceAspectRatio: number)
Event: cameraScopes, emitted through RCTDeviceEventEmitter / the existing NativeEventEmitter.
Fields:
  version: 1
  timestampUs: Android monotonic preview-offer timestamp in microseconds
  width, height: analyzed/cropped dimensions after the optional rotation, each 1..256
  rotation: 0 or 90 degrees clockwise
  sourceAspectRatio: preview aspect ratio before portrait rotation (1.5 or 16/9)
  demo: true for synthetic demo frames
  postLut: true (the exact effective JPEG also delivered to preview/capture, including LUT fallback)
  pixels: width * height
  clipLow, clipHigh: number of sampled pixels with ANY RGB channel equal to 0 or 255,
                     counted once per pixel for each endpoint; both may include the same pixel
  histogram: Base64 of 1024 Uint8 values, channel-major R, G, B, Y, 256 bins each
  waveform: Base64 of 4096 Uint8 values, row-major 64 columns x 64 brightness levels
  parade: Base64 of 6144 Uint8 values, channel-major R/G/B with 32 x 64 row-major grids
  vectorscope: Base64 of 4096 Uint8 values, row-major 64 x 64, Cb increases right, Cr increases up
Histogram count intensities use a common linear peak across RGBY. Density grids use logarithmic
count intensity, with a shared peak across RGB parade channels. Uint8 values represent intensity,
not the original raw counts. Zero means an empty bin. Waveform/parade top is 100%, bottom is 0%.
Y' = 0.2126 R + 0.7152 G + 0.0722 B on full-range, gamma-encoded JPEG values;
Cb = (B - Y') / 1.8556 and Cr = (R - Y') / 1.5748. Vectorscope targets are 75% RGB color bars.
The four arrays total 15360 binary bytes (20488 Base64 characters) per sample, plus small metadata.
JS validates schema, dimensions, clipping counts, exact buffer sizes and canonical Base64 padding;
its decoder does not rely on Node Buffer or atob on device.
