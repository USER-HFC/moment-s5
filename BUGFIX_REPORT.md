The host initially lacked a JDK. A portable JDK 17 was downloaded to ignored `.tools/` for verification. The optional host script uses ignored `.tools/android-all.jar` (`org.robolectric:android-all:15-robolectric-12650502`) and `.tools/react-android.jar` (classes extracted from `com.facebook.react:react-android:0.76.7:release`); alternative jar paths can be supplied with `MOMENT_ANDROID_JAR` and `MOMENT_REACT_JAR`. These are verification artifacts, not application dependencies. The separate javac run reported four missing optional annotation enum warnings and the bridge's existing deprecated-API notice; it did not produce an APK or validate Android resource/Kotlin/native-library packaging.

Primary references used to confirm protocol/format/clock details: OpenSession transaction-zero behavior is implemented in [AOSP's libmtp source](https://android.googlesource.com/platform/external/libmtp/+/master/src/ptp.c). The accepted Resolve 3D input-range header is documented and parsed in [OpenColorIO's Resolve cube reader](https://github.com/AcademySoftwareFoundation/OpenColorIO/blob/main/src/OpenColorIO/fileformats/FileFormatResolveCube.cpp). Android defines BOOTTIME as matching elapsedRealtimeNanos in the [AudioTimestamp API reference](https://developer.android.com/reference/android/media/AudioTimestamp#TIMEBASE_BOOTTIME).

No such failure was reproduced in the available tests; this audit did not add an unverified concurrency redesign.
