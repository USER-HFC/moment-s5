# 瞬间 Lumix / H5 相机原型

双击 index.html 可用；本地服务预览：在本目录执行 `python -m http.server 8765 --bind 127.0.0.1`。
桌面是原型评审台，可选手机尺寸、旋转；窄屏自动全屏，`?fullscreen=1` 可强制全屏。

## 设计约束

- 一套机位坐标：工具、预览、模式、快门从左至右。竖持时整套机位旋转，图标反向转正；不换成另一套滚动布局。
- 预览按比例完整适配可用区域。3:2 是完整样张；16:9 切换用于示意宽画幅（样张裁切），不发送相机设置。网格位于 image-frame，尺寸与显示影像严格一致，不延伸到黑边。
- 所有控件和面板是实色；不使用玻璃、背景模糊或半透明操作卡片。
- 菜单、对焦、LUT、延时、连接和相册可点开。模式与快门常驻。对焦框只演示自动对焦反馈，不冒充机身支持点选对焦。
- 静态样张，不代表实时取景。连接、快门、缓存、相册均为本会话演示，LUT 预置效果为 CSS 示意；文件选择不解析 LUT。
- 不包含 Android 闪屏修复，也不修改 RN 页面。确认交互方案后再实现原生预览。
