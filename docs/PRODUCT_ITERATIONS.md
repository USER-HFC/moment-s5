# 产品迭代：0.8.0-beta.5

依据 2026-11-07 对 v0.8.0-beta.4 release APK 的逐屏走查（模拟器，演示模式），以及对界面文案的检查。每一条都写明了现在的问题和完成标准。P0 指影响可用性或信息不实，P1 指明显降低体验，P2 指打磨。

## 迭代 1：上手、反馈和信息准确

| # | 级别 | 问题 | 完成标准 |
|---|---|---|---|
| 1.1 | P0 | 「连接诊断」在 RN 应用里不存在。原生有 `diagnostics()`，但没有任何界面调用；可是报错提示（「请检查连接诊断」）、beta.4 发布说明都让用户去看它 | 设置里新增「连接诊断」页：显示日志，可以复制和分享（系统分享面板），日志里不包含序列号。报错提示带「查看诊断」按钮，直接打开该页 |
| 1.2 | P0 | 未连接时，画面中央写「等待相机取景」，只有一个「体验演示」按钮；真正的「连接」入口是右上角的小图标 | 未连接时显示「未连接相机」，主按钮「连接相机」打开连接面板，次按钮「体验演示」，下面三步简短指引（相机选 PC(Tether)、数据线、手机开 OTG） |
| 1.3 | P1 | 未连接时，「相机未连接」「曝光 · 未连接」「照片 · 未连接」重复三遍，曝光行和「相机 —」显示一排横线 | 未连接时只保留一处状态；曝光行和相机电量在没有数据时隐藏，不显示横线占位 |
| 1.4 | P1 | 快门置灰时点了没有任何反应，用户不知道为什么 | 点按不可用的快门时给出原因：「请先连接相机」/「动态照片还在缓存，还需约 N 秒」/「正在保存上一张」 |
| 1.5 | P1 | 连接面板：三个方式排成两行（两个加一个整行），看起来像排版出错；关闭按钮写「完成」；USB 说明挤成一句话 | 三个方式等宽排成一行（分段控件）；关闭改为 ✕；USB 改成 3 个编号步骤（相机：设置 → USB → PC(Tether)；用支持数据的 USB-C 线；OPPO/ColorOS 在设置里开启 OTG） |
| 1.6 | P1 | Wi-Fi 页：协议术语一大段（「LUMIX Sync / Image App 遥控协议」），「实验」出现 3 次；「已手动连接相机 Wi-Fi」开关默认打开，含义不直观 | 用摄影用户能懂的话写编号步骤（相机开启 Wi-Fi 遥控拍摄 → 手机连上相机热点 → 填 IP，默认 192.168.54.1）；「实验」只在标签里出现一次；开关改为「我已在系统设置里连上相机 Wi-Fi」，并补一句说明 |
| 1.7 | P1 | 同一个概念用了多种说法：「实况」「动态」「LIVE」「Motion Photo」，演示也有「DEMO」「合成演示」「演示」 | 面向用户统一叫「动态照片」（缩写「动态」，相册角标可以保留 LIVE）；统一叫「演示」。所有界面文案、提示、分享菜单都改 |
| 1.8 | P1 | 保存提示是浅灰色的 Material 默认样式，和深色界面不搭，还盖住了照片/动态切换 | 统一的深色提示条，显示在拍摄区上方、不遮挡控件；保存成功后带「查看」，点了直接打开相册查看器里的这张 |
| 1.9 | P1 | 定时：第一次点直接开 10 秒，第二次点弹出模态框（「30秒」单独掉到第二行，按钮叫「完成」），选时间还藏在长按里 | 点「定时」在旁边弹出和 LUT/对焦同样风格的二级面板（关、2、5、10、30 秒），去掉模态框和长按；按钮标签显示当前状态（「定时 关」/「5 秒」） |
| 1.10 | P1 | 「3:2 / 16:9」只裁切预览，不影响照片；竖屏下「16:9」显示的是竖向框，容易误导 | 改成「构图参考框」：不裁切预览，只叠加参考线（关、16:9、1:1、4:5），名称写明是「参考」，不影响照片 |
| 1.11 | P2 | 演示模式：左上角「DEMO · 合成演示」中英重复；竖排水印「MOMENT / SYNTHETIC DEMO」和「相机 —」文字重叠 | 状态写「演示」；水印不能和 HUD 文字重叠（可以移到底部或缩小、降低透明度） |
| 1.12 | P2 | 动态缓存显示「缓存 3.0 / 3s」，是工程写法 | 改成「已缓存 3 秒 · 可拍」/「缓存中 1.2 秒」，加一条细进度条 |
| 1.13 | P2 | 「环境声」按钮只有图标表示状态，开和关不好分辨 | 标签显示状态：「收音 开」/「收音 关」，开启时高亮 |

## 迭代 2：设置、相册效率和细节打磨

| # | 级别 | 问题 | 完成标准 |
|---|---|---|---|
| 2.1 | P1 | 设置只有「关于」 | 增加偏好：拍摄后自动导出到系统相册、机身快门照片自动同步（开/关）、启动时记住上次的拍摄模式、网格、参考框和定时 |
| 2.2 | P1 | 设置里没有帮助入口 | 新增「使用指南」页（USB 和 Wi-Fi 的设置步骤、常见问题：连不上、传错照片、对焦方向），以及「反馈问题」入口（打开 GitHub Issues，并提示附上连接诊断） |
| 2.3 | P1 | 设置里看不到存储占用 | 「存储」：显示 App 内照片数量和占用空间，提供「清理已导出到系统相册的 App 内副本」，清理前要确认，并说明机身 SD 卡不受影响 |
| 2.4 | P1 | 按快门没有任何视觉或触感反馈 | 快门按下时画面短暂闪一下，加轻微震动；保存后相册按钮的缩略图用动画更新 |
| 2.5 | P1 | 相册只能一张一张导出或删除 | 网格里长按进入多选，可以批量导出、批量删除（删除前确认，只删 App 内副本） |
| 2.6 | P2 | 相册里找不到某一类照片 | 顶部加筛选：全部、照片、动态、机身同步 |
| 2.7 | P2 | 查看器只能点返回关闭 | 支持下滑关闭查看器 |
| 2.8 | P1 | 原生错误直接显示给用户，比如「PTP 指令 0x9404，响应 0x2019（机身忙）」 | 建立错误文案映射：给用户看的是人话和建议（「相机正忙，请稍后再按快门」），原始信息写进诊断日志 |
| 2.9 | P2 | 已连接时 HUD 只写「USB」/「Wi-Fi」 | 已连接时显示机型，例如「DC-S5 · USB」（数据来自 DeviceInfo 或 description） |
| 2.10 | P2 | 首次使用不知道从哪里开始 | 首次启动显示 3 张引导卡片（连接相机、拍动态照片、套用 LUT），可以跳过，只出现一次，之后可以在「使用指南」里再看 |
| 2.11 | P2 | 新加的这些页面没有在横屏和大字体下检查过 | 设置、诊断、指南、相册多选在横屏和 1.3 倍字体下都不溢出、不截断 |
| 2.12 | P0 | 分享菜单用的是 Android 系统对话框，最多显示 3 个按钮，「分享动态照片」和「取消」显示不出来，无法分享动态照片本身（迭代 1 中发现） | 改成应用内底部面板，列出全部分享方式和取消；没有对应文件的选项隐藏 |
| 2.13 | P2 | 连接诊断每行开头是开机后的毫秒数（如「192380」）；演示日志写「不代表 S5 实测」 | 显示为 `HH:mm:ss` 墙钟时间；文案改为与机型无关 |
| 2.14 | P2 | Wi-Fi 页输入框写「相机 Wi-Fi SSID」 | 改为「相机 Wi-Fi 名称」 |
| 2.15 | P2 | 动态模式下 HUD 同时显示「动态 · 可拍」和「已缓存 3 秒 · 可拍」 | 「可拍」只出现一次 |

每一项完成后都要有测试或截图作为证据；没有真机的内容要在发布说明里标明「未在真机验证」。
